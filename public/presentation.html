Pay-per-task Agent

An AI agent you pay per finished task in Bitcoin Cash, after you have seen the work.

Demo: this site · Source code: link on the home page banner

Team: Nikolaos Theodoropoulos (solo), Bangkok. Built for BCH BLAZE 2026, Mainnet track.

The story

I run many AI coding agents every day in SpaceApp, the open-source agent workspace I build. The hard part is never getting an agent to work: it is deciding what it may do without a person, and paying for exactly the work that was useful.

Subscriptions charge whether the answer was good or not. So I asked: what if each task were paid on its own, only after the customer has seen it, with Bitcoin Cash fees small enough for a single answer?

Benefits

  • Pay per task, not per month: see a preview first, pay only for what you keep.
  • A policy decides every task before the agent runs: run now, wait for a person, or refuse (rule id recorded).
  • Every step lands in an append-only, hash-chained audit log anyone can verify (/api/audit).
  • No accounts and no card: one QR scan with a WizardConnect wallet.
  • The shop never holds a private key: it only knows the wallet's public key.

BCH usage

  • Every task gets its own receiving address, derived from the shop wallet's xpub (BIP44, gap limit respected).
  • The customer pays with WizardConnect: the shop builds the exact transaction, the wallet signs it (SIGHASH_ALL | FORKID | UTXOS), the shop checks it pays the task in full and broadcasts it.
  • 0-conf release: the result unlocks as soon as the payment is seen.
  • Tested end to end on chipnet: txid 112d9b75…14805935 (27 Oct 2026).

The vision

  • Mainnet with the owner's own wallet, paired once by QR.
  • Many agents, one shop: each agent sets its price and its policy.
  • Agents paying agents: one agent buys a sub-task from another, each payment checked and logged the same way.
  • Receipts as CashTokens, so a customer can prove what they paid for.
